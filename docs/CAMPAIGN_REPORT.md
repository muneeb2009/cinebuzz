## Measurement and tracking
Every dashboard value is labelled Simulated. Data source is this browser session’s local event log, stored in sessionStorage. No external analytics or personal details are sent. This is prototype interaction evidence, not audience-research evidence.

| Event | Trigger / method | KPI / formula | Status |
|---|---|---|---|
| page_view | One event on app mount / page load | Prototype visits = count | Simulated |
| trailer_play | Open trailer placeholder | Trailer interactions = count; not actual playback duration | Simulated |
| showtimes_view | Navigate to showtimes | Showtime checks = count | Simulated |
| showtime_selected | Choose a time | Time selections = count | Simulated |
| booking_started | Continue from showtimes | Mock-booking starts = count | Simulated |
| seat_selected | Toggle a seat | Seat interactions = count, including deselections | Simulated |
| mock_payment_started | Submit valid demo details | Payment-stage starts = count | Simulated |
| mock_booking_completed | Complete mock payment once | Completed mock bookings = count | Simulated |
| sample_ticket_viewed | Open sample ticket | Sample ticket views = count | Simulated |

Conversion = completed mock bookings / prototype page loads × 100. Zero denominator gives 0%. Repeat bookings can exceed visits; this limitation is shown. No unique-user attribution, deduplication across devices, real sales, advertising-source attribution or server persistence is claimed.

## Optimization recommendations
1. After the real teaser is provided, compare trailer opens to actual playback starts and completions. Until then, do not interpret placeholder opens as video engagement.
2. Compare booking starts with completions during supervised usability sessions. If visitors stop at details, test more visible sample-data guidance and clearer progress labels before reallocating media spend.
3. Compare genre-reveal and mystery-signal creatives with equal simulated budgets. Select a winner only with clearly labelled observations; do not manufacture engagement claims.

## Final pitch narrative
For judges acting as a producer or distributor: CineBuzz makes a mysterious sci-fi concept understandable and actionable. A consistent creative family attracts interest; the website connects discovery to a measurable mock booking. The prototype is intentionally safe to demonstrate: no real charges, seat reservations, or valid entry tickets. The next investment is a final trailer, structured usability testing and approved campaign distribution—not payment infrastructure.
